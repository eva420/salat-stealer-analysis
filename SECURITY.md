# Security Policy

This repository is published threat research at TLP:CLEAR. It contains no running service.

## Corrections and new sightings
Open an [issue](https://github.com/eva420/salat-stealer-analysis/issues/new/choose) or a pull request. Defang indicators (`evil[.]com`, `1.2.3[.]4`) and link public sources where possible.

## Sensitive reports
If something must not be public (for example personal data that slipped into this write-up, or a lead for law enforcement), use the contact listed on the [eva420 profile](https://github.com/eva420) rather than opening a public issue.

No individual attribution is published or accepted here.
